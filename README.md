# Visualization-methods
Histogram

Description:
A histogram shows the distribution of a numerical variable by dividing data into bins (ranges) and displaying their frequency.

Used For:

Understanding data distribution

Checking skewness

Identifying concentration of values

Example:
Histogram of Spending Score shows how customers are distributed across spending levels.

📊 2️⃣ Bar Chart

Description:
A bar chart compares values across different categories using rectangular bars.

Used For:

Comparing categories

Showing counts or averages

Example:
Bar chart of Average Monthly Income by Gender compares income levels between males and females.

📊 3️⃣ Line Chart

Description:
A line chart shows trends over time by connecting data points with lines.

Used For:

Time-series analysis

Sales trends

Growth patterns

Example:
Line chart of Total Purchase Amount per Month shows monthly sales trend.

📊 4️⃣ Scatter Plot

Description:
A scatter plot shows the relationship between two numerical variables using dots.

Used For:

Correlation analysis

Detecting relationships

Identifying clusters

Example:
Scatter plot of Monthly Income vs Spending Score shows how income affects spending behavior.

📊 5️⃣ Box Plot

Description:
A box plot shows the distribution of data using quartiles and identifies outliers.

Shows:

Median (middle line)

Q1 & Q3 (box edges)

Whiskers (range)

Outliers (points outside)

Used For:

Comparing distributions

Detecting outliers

Understanding spread

Example:
Box plot of Purchase Amount by Product Category compares spending variation across categories.

📊 6️⃣ Pie Chart

Description:
A pie chart shows percentage distribution of categories as slices of a circle.

Used For:

Showing proportion

Category distribution

Example:
Pie chart of Product Category Distribution shows contribution of each category.
